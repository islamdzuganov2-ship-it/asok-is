### METRICS INPUT FLOW
```
MetricsInputPage.tsx (periodId из URL params)
  ──GET /api/v1/assessments/{id}/metrics──►
                                            SELECT AssessmentValue
                                            JOIN MetricCatalog
                                            WHERE period_id = {id}
  ◄──EditableMetricOut[]──────────────
  Table: InputNumber val_a/val_b
  dirtyIds Set (tracking изменений)
  
  ──PUT /api/v1/assessments/{id}/metrics──►
                                            calculate_metric(a, b, formula_type)
                                              DIRECT:  X = clamp(a/b, 0,1)
                                              INVERSE: X = clamp(1-a/b, 0,1)
                                            UPDATE AssessmentValue
                                            → calculated_x, quality_level
  ◄──{updated: N, errors: []}─────────
  refetch() → обновление таблицы
```

### CALCULATION ENGINE
```
calculation_engine.py  ←────────────────────────────────┐
                                                          │
calculate_metric(a, b, formula_type):                     │
  b == 0      → (0.0, "Невозможно измерить")             │
  DIRECT:  X = clamp(a/b, 0, 1)                          │
  INVERSE: X = clamp(1 - a/b, 0, 1)                      │
                                                          │
  X >= 0.81 → "Высокий уровень"          ────────────────┤
  X >= 0.61 → "Уровень выше среднего"                    │
  X >= 0.41 → "Средний уровень"           RAG цвета:     │
  X >= 0.21 → "Уровень ниже среднего"    🟢🟡🔴⚫         │
  X >  0.00 → "Низкий уровень"                           │
  X == 0.00 → "Невозможно измерить"                      │
                                                          │
  вызывается из:                                          │
    assessments.py save_assessment_metrics()  ────────────┤
    tasks.py parse_excel_task()  ─────────────────────────┘
```

## 🗃️ Схема базы данных

```
users (нет в миграции 001 ⚠️)
  id UUID PK | username | password_hash | role | is_active

systems
  id UUID PK | name | code UNIQUE | status_lc | criticality_class
  is_active | is_deleted | created_at | updated_at

metric_catalog
  id INT PK | characteristic | subcharacteristic
  formula_type (DIRECT|INVERSE) | description | data_source | is_active

assessment_periods
  id UUID PK | system_id FK→systems | period VARCHAR(20)
  status (DRAFT|IN_PROGRESS|COMPLETED)
  UNIQUE(system_id, period)

assessment_values
  id UUID PK | period_id FK→assessment_periods | metric_id FK→metric_catalog
  val_a | val_b | calculated_x | quality_level
  expert_comment | artifact_links JSONB | data_source

expert_judgment_history
  id UUID PK | assessment_value_id FK→assessment_values
  original_level | adjusted_level | justification_text
  linked_risk_task | created_by FK→users | created_at
```
