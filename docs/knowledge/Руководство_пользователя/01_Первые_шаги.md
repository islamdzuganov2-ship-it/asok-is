# Первые шаги

## 1. Как открыть систему
- Локально: `http://localhost:3000`.
- По публичной ссылке (если включён доступ из интернета) — адрес вам выдаёт администратор
  (например, `https://asok.asokis.ai`).

## 2. Вход в систему
На странице входа введите логин и пароль. В демо-режиме доступны три учётные записи —
по одной на каждую роль:

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `Admin123!` | Топ-менеджмент |
| `manager` | `Manager123!` | Менеджер по качеству |
| `analyst` | `Analyst123!` | Аналитик |

После входа система автоматически открывает **«ваш» дашборд** в зависимости от роли — не нужно
искать нужный раздел вручную.

## 3. Что на экране (общие элементы)
- **Левое меню** — пункты зависят от роли (у каждой роли свой набор).
- **Шапка сверху:**
  - слева — название «Система оценки качества»;
  - справа — **переключатель «Демо ↔ LLM»** с индикатором готовности модели (зелёная точка —
    встроенный AI готов), и **ваше имя · роль** с кнопкой **«Выйти»**.

## 4. Переключатель «Демо ↔ LLM»
- **Демо** (по умолчанию) — показываются заранее подготовленные демонстрационные данные.
  Удобно для презентаций: всё стабильно и наглядно.
- **LLM** — система берёт реальные данные и формирует **AI-резюме встроенной языковой моделью**
  (работает локально, без интернета). Индикатор рядом показывает, загружена ли модель;
  если нет — система честно выдаёт текст-заглушку, ничего не «выдумывая».

## 5. Цветовая индикация качества (RAG)
Везде используется единая спокойная (пастельная) шкала уровней:

| Цвет | Уровень | Балл |
|---|---|---|
| 🟩 шалфейный | Высокий | ≥ 81% |
| 🟩 светлый шалфей | Выше среднего | 61–80% |
| 🟨 приглушённое золото | Средний | 41–60% |
| 🟧 мягкая глина | Ниже среднего | 21–40% |
| 🟥 приглушённый терракот | Низкий | 1–20% |
| ⬜ серый | Невозможно измерить | 0% |

## 6. Базовые понятия (коротко)
- **ИС** — информационная система (например, «АБС Ядро», «Мобильный банк»).
- **Характеристика** — одно из 8 свойств качества по ISO 25010 (надёжность, безопасность и т.д.).
- **Метрика** — конкретный показатель внутри характеристики, считается по формуле из факта и плана.
- **Мера качества** — задача на улучшение: что сделать, кто отвечает, к какому сроку.
