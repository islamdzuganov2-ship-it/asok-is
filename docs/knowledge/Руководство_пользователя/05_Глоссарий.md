# Глоссарий

- **ИС (информационная система)** — приложение/система банка, качество которой оценивается
  (например, «АБС Ядро», «Мобильный банк», «CRM ОПК»).
- **Характеристика качества** — одно из 8 свойств по ISO/IEC 25010: функциональная пригодность,
  производительность, совместимость, удобство использования, надёжность, защищённость,
  сопровождаемость, переносимость.
- **Подхарактеристика** — уточнение характеристики (например, у «Надёжности» — доступность,
  отказоустойчивость, восстанавливаемость, зрелость). Всего 31 подхарактеристика.
- **Метрика** — измеримый показатель внутри подхарактеристики.
- **val_a / val_b** — исходные значения метрики: `val_a` — факт, `val_b` — план/база.
- **Формула DIRECT / INVERSE** — способ расчёта коэффициента:
  - `DIRECT`: X = A / B (чем больше, тем лучше);
  - `INVERSE`: X = 1 − A / B (чем меньше «плохого», тем лучше).
- **Коэффициент X** — результат расчёта метрики, число от 0 до 1; в процентах — это «балл».
- **Уровень качества** — словесная градация по баллу: Высокий ≥81%, Выше среднего ≥61%,
  Средний ≥41%, Ниже среднего ≥21%, Низкий >0%, Невозможно измерить 0%.
- **RAG** — цветовая индикация (красный-жёлтый-зелёный, в системе — приглушённые тона).
- **Оценочный период** — отрезок времени оценки ИС в формате `Q{1-4}-{ГГГГ}` (например, Q2-2026).
- **Профессиональное суждение** — обоснованная экспертная оценка менеджера по качеству по метрике;
  может корректировать уровень и порождать меру.
- **Мера качества** — задача на улучшение/исправление: формулировка, ответственный (ФИО и должность),
  срок. Проходит цикл: ожидает решения → одобрена/отклонена → выполнено/не выполнено.
- **Риск / База рисков** — накопительный реестр знаний о типовых рисках и мерах их минимизации;
  используется встроенной LLM для обоснования рекомендаций.
- **Технический долг** — накопленные нерешённые проблемы качества; в системе отражается набором
  счётчиков и «burndown» (сколько мер закрыто).
- **AI-резюме** — краткий управленческий вывод, который формирует встроенная языковая модель (LLM)
  строго по переданным цифрам, без выдуманных значений.
- **LLM** — встроенная языковая модель, работает локально (без внешних сервисов).
- **ЛПР** — лицо, принимающее решения (в системе — роль «Топ-менеджмент»).
- **SoD (разделение обязанностей)** — принцип: тот, кто ставит меру, не принимает по ней решение;
  кто решает, не отчитывается о выполнении.
