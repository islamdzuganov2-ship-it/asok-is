## Стек (кратко)
- **Backend:** Python 3.11, FastAPI, SQLAlchemy (async), Alembic, Celery+Redis, llama-cpp-python (LLM).
- **Frontend:** React 18 + TypeScript, Vite 5, Redux Toolkit (+RTK Query), Ant Design, ECharts.
- **Данные:** PostgreSQL 14, Redis 7.
- **Инфра:** Docker Compose; публичный доступ — Cloudflare tunnel / named / ngrok / прямой Caddy.
