# Зависимости и граф импортов

## 1. Внешние зависимости
**Backend** (`backend/requirements.txt`): fastapi, uvicorn, pydantic/-settings, sqlalchemy[asyncio],
asyncpg, alembic, psycopg2-binary, python-jose, passlib[bcrypt], bcrypt, python-multipart, celery,
redis, httpx, openpyxl, pandas, **llama-cpp-python** (in-process LLM), pytest.

**Frontend** (`frontend/package.json`): react 18, react-dom, react-router-dom, @reduxjs/toolkit,
react-redux, antd, @ant-design/icons, echarts + echarts-for-react, dayjs, vite 5, @vitejs/plugin-react,
typescript, axios.

## 2. Внутренний граф (ключевые рёбра)
**Backend:**
```
main.py → api/v1/api.py → {auth, systems, assessments, metrics, reports, excel_upload, risk_base}
reports.py → services/llm_service.py → models/risk_base.py (grounding)
reports.py / excel_upload.py → services/calculation_engine.py
*.endpoints → api/deps.py (get_db, require_role) → core/{security, database, config}
risk_base.py / excel_upload.py → models/* → db/base.py (Base)
workers/tasks.py → services/llm_service.py
```
**Frontend:**
```
main.tsx → App.tsx → AppLayout + pages/*
pages/* → store (slices/api) + components/* + data/mockScaleData + theme/ragPalette + constants/roles
ExecutiveDashboard → {ActionInsightModal, MeasureDecisionModal, MeasuresRegistryCard, TechDebtCard}
ManagerDashboard → {ProfessionalJudgmentModal, MeasureDecisionModal}
DashboardPage → LevelHeatmap
governanceSlice ← seed из data/mockScaleData (SCALE_PROPOSALS)
```

## 4. Точки сопряжения, требующие синхронности
- **Коды/подписи ролей:** backend (`models/user.py`, deps) ↔ frontend (`constants/roles.ts`).
- **Формат уровней качества:** `calculation_engine.map_to_level` ↔ `theme/ragPalette.levelLabel`
  (есть рассинхрон формулировок «Выше среднего» vs «Уровень выше среднего» — к исправлению).
- **API base URL:** `VITE_API_BASE_URL=/api/v1` (относительный) ↔ прокси Vite ↔ backend `/api/v1`.
- **Модель данных риска:** `risk_base` (БД) ↔ `schemas/risk_base` ↔ `RiskBasePage` (типы Risk).
