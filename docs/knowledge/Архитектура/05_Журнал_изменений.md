# Журнал изменений архитектуры

> **Регламент.** Любое изменение, затрагивающее структуру кода, обязано фиксироваться здесь:
> новый/удалённый файл или модуль · новый эндпоинт или роут · новая модель/таблица или миграция ·
> новый слайс состояния/контекст · новая внешняя зависимость · изменение потока данных или
> точки сопряжения backend↔frontend · новый сервис Docker/инфраструктуры.
>
> Формат записи: `ГГГГ-ММ-ДД — что изменилось — какие файлы — влияние на [[01_Общая_картография]]/[[02_Backend]]/[[03_Frontend]]/[[04_Зависимости]]`.
> При изменении — обновить и соответствующий документ ветки, не только этот журнал.

## 2026-06-27 — BASELINE (точка отсчёта)
Зафиксирована текущая архитектура целиком:
- **Backend:** FastAPI `/api/v1` (auth, systems, assessments, metrics, reports, excel, risks);
  модели users/systems/metric_catalog/assessment*/matrices/risk_base/audit; сервисы
  calculation_engine, llm_service (in-process llama-cpp), excel_importer; Celery+Redis; Alembic 001–003.
- **Frontend:** Vite/React SPA; роутер с ролевой маршрутизацией; 3 дашборда; governance-контур мер
  (Redux+localStorage); RTK Query/fetch; пастельная RAG-палитра; подписи ролей в constants/roles.
- **Инфра:** Docker Compose (postgres/redis/backend/celery/frontend) + публичный доступ
  (профили tunnel/named/ngrok/direct), Vite-прокси `/api`, относительный API base.
- **Зафиксированы дубли/legacy** к консолидации (см. [[04_Зависимости]] §3).

Документы baseline: [[АОК ИС/Архитектура/00_Индекс]], [[01_Общая_картография]], [[АОК ИС/Архитектура/02_Backend]], [[03_Frontend]], [[04_Зависимости]].
