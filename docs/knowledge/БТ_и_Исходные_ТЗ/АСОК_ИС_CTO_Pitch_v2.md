## Слайд 1 — Проблема + Продукт

**Заголовок:** Половина ваших систем — ниже среднего качества. Вы об этом узнаёте только в продакшне.

**Три факта:** 47% средний индекс · 71% критичных ниже порога · 8/11 Mission Critical в риске

**АСОК ИС делает:**
- Управленческий дашборд + heatmap
- AI-резюме рисков (LLM, без галлюцинаций, RAG из базы рисков)
- Governance: меры → решение → контроль (SoD)
- Burndown техдолга по периодам
- Накопительная база рисков
- Требования качества → в договор с вендором

## Слайд 2 — Ценность для CTO/CEO

| Блок | Вопрос | Ответ |
|------|--------|-------|
| **Видимость** | Зачем? | Вы перестаёте управлять вслепую. Единый дашборд: топ проблемных ИС, heatmap, кто отвечает. |
| **Контроль** | Для чего? | Плохой код не уходит в прод. Score ниже порога → нет перехода в ПЭ без решения Совещательного органа БИТ. |
| **Деньги** | Какой ROI? | 8 из 11 Mission Critical в риске сейчас. Инцидент = десятки млн ₽ + риск перед ЦБ. Дефект в тесте дешевле в 5–10×. |
| **Вендоры** | Рычаг? | Score — условие договора. Финответственность вплоть до отказа от оплаты. Трассировка по релизам. |

**CTA:** Пилот 3 ИС / 4 недели → Score + карта рисков + план. Весь портфель — 1 квартал. On-prem (Docker).
