## Ключевые архитектурные решения

| Решение | Где описано | Суть |
|---------|-------------|------|
| Модульный монолит вместо микросервисов | ТЗ-01, ADR-001 | Границы модулей проверяются архитектурным тестом |
| Расчёт отделён от интерпретации | ТЗ-05, раздел 4 | Вердикт выносит движок правил; LLM только объясняет |
| Знания вне весов модели | ТЗ-05, раздел 6 | «Резервный мозг» в JSONL — замена GGUF не обнуляет опыт |
| Разделение полномочий (SoD) | ТЗ-02, раздел 3 | Автор предложения не может утвердить его |
| Неизмеримые метрики исключаются | ТЗ-06, раздел 2.5 | Отсутствие данных — не плохое качество |
| Только локальная LLM | ТЗ-05, раздел 1 | Данные не покидают банковский периметр |
| Модель-агностичность | ТЗ-05, раздел 3 | Любой GGUF в каталоге работает без правки кода |
