# АСОК ИС — ТЗ v14: Динамика качества, аномалии, аудит мер, ролевые данные

> **Статус: реализовано и протестировано 2026-07-06** (backend 118 юнит + 6 e2e; frontend
> 14 юнит + типконтроль). Полная версия — `docs/ТЗ_Дашборды_Динамика_v14.md` в репозитории.
> Согласовано с кодом: все пункты ниже имеют реализацию и тестовое покрытие.

## Требования (из запросов на доработки) и реализация

1. **Карточка «Качество информационной системы»** — в самом верху дашборда «Динамика качества»,
   интегральный балл по кварталам (как «Качество по характеристикам во времени»).
   → `QualityDynamicsPage.tsx`, `DYNAMICS[*].system` **[фронт]** ✅
2. **Все системы на одной диаграмме / выбор системы** — пункт «— Все системы —» в селекторе;
   клик по линии → переход к системе. **[фронт]** ✅
3. **Аномалии с причинами** — |Δ| ≥ 12 п.п. подсвечены; всплывашка с причиной от МК; при
   отсутствии — предупреждение + **уведомление МК** в колокольчик (агрегация по системам);
   в модалке аномальные кварталы помечены, поле причины обязательное. **[фронт]** ✅
4. **Связь карточки «Заполненные профсуждения» с характеристикой** — тег и фильтр по выбранной
   характеристике (как у «Метрики характеристики "X"»), данные из `professional_judgments`;
   для АОКИС засеяны суждения с фокусом «Функциональная пригодность». **[фронт+бэк]** ✅
5. **Правки мер топ-менеджером + аудит** — кнопка «Внести правки» (название, обоснование,
   ожидание от ЛПР, ответственный, срок); каждая правка → история изменений (кто/когда/
   было→стало); история — кнопка-иконка без текста (`HistoryOutlined`).
   → `governanceSlice.editProposal`, `MeasureDecisionModal` **[фронт]** ✅
6. **Ролевые данные (моки+БД пересозданы)** — сценарные детерминированные данные:
   МК — метрики/формулы/суждения; CIO/CTO/CEO — меры/эскалации/задачи качества.
   → `mockScaleData.ts` v2, `seed_demo.py` v2 (4 ИС × 6 кварталов, СИИ-контур, чистка мусора).
   **[фронт+бэк]** ✅
7. **Сквозная проливка** — все дашборды читают одни таблицы; исправлены DEF-12/13/14
   (последний период, хронология кварталов, шум уведомлений); e2e-тесты консистентности.
   → `app/shared/periods.py`, `test_e2e_dashboards.py` **[бэк]** ✅
