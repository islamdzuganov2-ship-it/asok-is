## «Обучение» = Modelfile + системный промпт + few-shot
- Роль: ИТ-директор/аналитик качества (МК_8.1/ISO 25010).
- Выход: резюме 2–3 предложения + 1 рекомендация + просевшая характеристика, деловой стиль RU.
- Guardrails: только переданные цифры, без выдумок; нет данных → сказать прямо.
- Modelfile: `FROM qwen2.5:1.5b-instruct` + `SYSTEM` + `temperature 0.2` →
  `ollama create asok-model -f backend/llm/Modelfile`.
- Eval: ≥50 симв., русский, есть рекомендация, нет «выдуманных» чисел, ≤5 c CPU.
