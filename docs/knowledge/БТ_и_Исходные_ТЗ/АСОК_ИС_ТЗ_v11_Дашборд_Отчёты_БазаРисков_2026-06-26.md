# АСОК ИС — ТЗ v11: Дашборд, «Отчёты и реестры», новая «База рисков»

> Продолжает [[АСОК_ИС_ТЗ_v10_LLM_MVP_2026-06-25]]. Код НЕ изменён — целевое состояние «к применению по команде».

## R1. Доработка дашборда
- Базовый `/dashboard` → точка входа по ролям + KPI-плитки (индекс, проблемные ИС, открытые риски, меры на одобрение).
- Управленческий `/dashboard/executive`: связать с API (`/reports/executive-dashboard`) вместо `mockDashboards.ts`;
  `aiInsights` — от LLM, не хардкод; тултип + клик по ячейке heatmap → модалка (кто отвечает / с кого спрашивать / действия);
  Risks Burndown по реальным данным; спокойная палитра, без перегруза.

## R2. «Отчёты и реестры» (`/reports`)
- Экспорт xlsx/pdf; фильтры (ИС/характеристика/RAG/срок/поиск); кросс-период и динамика;
  колонка «Статус меры» (governance); новая вкладка «Реестр мер качества» (журнал PENDING/APPROVED/REJECTED).

## R3. Новая вкладка «База рисков» (`/risks`) — пополняемая, источник для LLM
- Отличие от `risk_matrices` (привязан к периоду, CASCADE): **сквозной накопительный реестр знаний** для LLM (RAG).
- Таблица `risk_base`: code, title, category, characteristic/subcharacteristic, description, consequence,
  mitigation, severity, likelihood, triggers, keywords/embedding, source(manual/excel/governance/llm),
  system_id?, status(active/archived), аудит.
- Функции: ручное добавление/редактирование (модалка), импорт из периода и из xlsx, авто-черновик при
  `Proposal.createRisk=true`, архив вместо удаления.
- LLM: `GET /risks/search?q=` → top-N в промпт `generate_ai_summary_task` → обоснованные рекомендации и
  предложение `mitigation` из базы (без галлюцинаций). Post-MVP: pgvector, обогащение одобренными мерами.
- RBAC: чтение всем; запись — QUALITY_MANAGER/ADMIN; топ-менеджмент — read-only как обоснование.
- API: `GET/POST /risks`, `PATCH /risks/{id}`, `POST /risks/{id}/archive`, `GET /risks/search`, `POST /risks/import/{period_id}`.

## План внедрения (только по команде)
