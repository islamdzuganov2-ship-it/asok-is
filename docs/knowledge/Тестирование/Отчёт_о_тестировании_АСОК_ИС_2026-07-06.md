## 3. Пользовательское тестирование (ролевые сценарии)

**Сценарий МК (manager/Manager123!):** дашборд МК → выбор ИС → метрики характеристики →
суждение → карточка суждений фильтруется по выбранной характеристике → «Динамика качества» →
аномалия без причины подсвечена → клик → ввод причины → уведомление уходит из колокольчика. ✅

**Сценарий топ-менеджера (cto/Cto12345! — новый демо-пользователь):** управленческий дашборд →
меры на одобрение → карточка меры → правка ответственного/срока через «Внести правки» →
запись в истории (иконка аудита) → одобрение с комментарием → эскалации с причинами от МК
и решениями «запросить меры». ✅

**Сценарий аналитика (analyst/Analyst123!):** оценка ИС → БД содержит 6 кварталов
сценарных данных 4 ИС (АБС стабильна; CRM деградирует 73→51; HR растёт 51→77; АОКИС — слабая
ФП), 2 метрики HR честно «невозможно измерить». ✅
