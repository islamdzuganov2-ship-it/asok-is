## 1. Как читать матрицу

| Колонка | Смысл |
| :--- | :--- |
| **БТ** | бизнес-требование заказчика |
| **ТЗ** | документ и задача, где требование формализовано |
| **Реализация** | статус из сквозной трассировки |
| **Автотесты** | покрытие автоматическими тестами (backend pytest / frontend vitest / статические проверки) |
| **Ручные сценарии** | ID сценариев из `05_Тестовые_сценарии.md` |
| **Покрытие** | 🟢 полное · 🟡 частичное · 🔴 отсутствует |

**Правило зачёта:** покрытие считается **полным**, только если есть и автотест, и подтверждающий ручной сценарий, либо автотест напрямую проверяет бизнес-правило. Наличие «зелёного» кода без теста — покрытие 🔴.
