# АСОК ИС — Единый реестр бизнес-требований (БТ)

**Версия:** 1.0
**Дата:** 2026-08-15
**Статус:** консолидировано для стабилизации
**Источник:** 33 сессии диалога с заказчиком (2026-06-25 … 2026-08-14), 132 уникальные реплики; исходное ТЗ v2.1 от 2026-05-17; пул ТЗ `docs/ТЗ_*`; бэклоги `docs/BACKLOG*.md`.

---

## 0. Как читать документ

| Поле | Значение |
| :--- | :--- |
| **ID** | `БТ-NNN` — сквозной номер бизнес-требования |
| **Формулировка** | требование в редакции, максимально близкой к словам заказчика (нормализована грамматика, смысл не изменён) |
| **Источник** | дата реплики заказчика (`ГГГГ-ММ-ДД`) или документ-первоисточник |
| **Домен** | функциональная область |

> Статус реализации по каждому БТ — в `04_Сквозная_трассировка.md`. Здесь фиксируется **только требование**, без оценки его выполнения.

**Принцип полноты:** ни одно высказанное требование не отброшено. Требования, впоследствии отменённые или изменённые самим заказчиком, сохранены с пометкой «⟲ переопределено в БТ-NNN» — чтобы история решений не терялась.

## 3. Оценка качества ИС

### 3.1 Модель качества и расчёт

| ID | Формулировка | Источник |
| :--- | :--- | :--- |
| **БТ-050** | Провести доскональную вычитку **ISO 25010**: все характеристики и подхарактеристики, разложить в таблицу со столбцами: номер, название характеристики, название подхарактеристики, описание (что показывает, какие артефакты и данные подтверждают), формула расчёта. | 2026-06-29 |
| **БТ-051** | То же самое отдельно для **ГОСТ**, и построить таблицу из трёх вкладок: ISO / ГОСТ / сравнение отличий. | 2026-06-29, 2026-06-30 |
| **БТ-052** | Расчёт метрики выполняется **на бэкенде на Python** (не generated columns в БД); в БД сохраняется готовое значение. Формула: `DIRECT` = A/B, `INVERSE` = 1 − A/B, с клампом в диапазон 0..1. | ТЗ v2.1 |
| **БТ-053** | Маппинг уровней качества: ≥0.81 высокий, ≥0.61 выше среднего, ≥0.41 средний, ≥0.21 ниже среднего, иначе низкий. При B = 0 — «Невозможно измерить». | ТЗ v2.1 |
| **БТ-054** | Оценка проводится **по всем 8 характеристикам и всем без исключения подхарактеристикам** ISO 25010. | 2026-06-26 |
| **БТ-055** | **Проработать веса подхарактеристик** (задача №13 риск-экономического контура). | 2026-08-04 |
| **БТ-056** | Разработать **методологию определения способов несоответствия подхарактеристик** (задача №5). | 2026-08-04 |
| **БТ-057** | Убрать из UI и документации все упоминания «**ISO 25010 / МК_8.1**» в связке. | 2026-07-02 |
