# Документация АСОК ИС

> **Проект:** АСОК ИС — Автоматизированная Система Оценки Качества Информационных Систем
> **Актуализировано:** 2026-08-02

Автоматизация оценки, мониторинга и управления качеством информационных систем в банковской среде на основе **ISO/IEC 25010:2023** и **ГОСТ Р 59898-2021**, с локальной LLM-аналитикой в закрытом контуре.

## Ключевые архитектурные решения

| Решение | Где описано | Суть |
|---------|-------------|------|
| Модульный монолит вместо микросервисов | ТЗ-01, ADR-001 | Границы модулей проверяются архитектурным тестом; сложность распределённой системы не оправдана масштабом |
| Расчёт отделён от интерпретации | ТЗ-05, раздел 4 | Вердикт выносит детерминированный движок правил; LLM только объясняет |
| Знания вне весов модели | ТЗ-05, раздел 6 | «Резервный мозг» в JSONL — замена GGUF не обнуляет накопленный опыт |
| Разделение полномочий (SoD) | ТЗ-02, раздел 3 | Автор предложения не может утвердить его; проверка в бизнес-логике, а не в UI |
| Неизмеримые метрики исключаются | ТЗ-06, раздел 2.5 | Отсутствие данных — не плохое качество; иначе интегральный показатель искажается |
| Только локальная LLM | ТЗ-05, раздел 1 | Данные не покидают банковский периметр; внешние API не используются |
| Модель-агностичность | ТЗ-05, раздел 3 | Любой GGUF в каталоге работает без правки кода |

## Проверка качества

Тесты бэкенда (требуется поднятый стек):

```bash
docker compose exec -T backend python -m pytest -q
```

Сквозные тесты дашбордов:

```bash
docker compose exec -T -e ASOK_E2E=1 backend python -m pytest -q
```

Тесты фронтенда:

```bash
docker exec -w /app asok_frontend npm test
```

Типконтроль фронтенда:

```bash
docker exec -w /app asok_frontend npm run typecheck
```

Контраст интерфейса (WCAG 2.1 AA, выполняется без Docker):

```bash
npm run check:contrast
```

Подробности — [ТЗ-04, раздел 14](./ТЗ_04_Бэкенд_API_Модули.md) и [ТЗ-03, раздел 6.8](./ТЗ_03_Фронтенд_Интерфейс.md).
