# Правовая охрана АСОК ИС: перечень необходимых документов

> **Версия:** 1.0
> **Дата:** 2026-08-25
> **Статус:** рабочий перечень для подготовки подачи
> **Юрисдикция:** Российская Федерация, Роспатент (ФИПС)

Документ отвечает на вопрос «что нужно собрать, чтобы запатентовать систему». Он делит
охрану на **четыре независимых трека**, перечисляет комплект документов по каждому и
указывает, **из каких материалов репозитория** этот комплект собирается.

> ⚠️ **Дисклеймер.** Это инженерно-организационный чек-лист, а не юридическое заключение.
> Формы заявлений, размеры пошлин и льгот меняются — актуальные редакции проверять на
> сайте ФИПС перед подачей. Формулу изобретения и описание готовит патентный поверенный.

---

## 0. Ключевая развилка: что именно охраняем

Программа для ЭВМ **как таковая** не является объектом патентного права (п. 5 ст. 1350 ГК РФ).
Поэтому АСОК ИС охраняется не одним документом, а комплектом:

| Трек | Объект | Что даёт | Срок |
| :--- | :--- | :--- | :--- |
| **A. Изобретение** | **способ** оценки и управления качеством ИС, реализуемый системой (+ система как устройство) | монополия на техническое решение | 20 лет |
| **B. Программа для ЭВМ** | исходный код АСОК ИС | свидетельство о госрегистрации, фиксация авторства и даты | бессрочно (авторское право) |
| **C. База данных** | каталог метрик/весов/бенчмарков, «резервный мозг» LLM | свидетельство на БД + смежное право изготовителя | 15 лет с обновления |
| **D. Ноу-хау (секрет производства)** | методики расчёта, промпт-инжиниринг, датасеты обучения | охрана без раскрытия, ст. 1465 ГК | пока сохраняется режим |

**Рекомендация по последовательности:** сначала **B** и **C** (быстро, дёшево, фиксирует дату),
параллельно патентный поиск по **A**, затем заявка на изобретение. **D** оформляется приказом
о коммерческой тайне до любой публикации.

**Критично:** заявка на изобретение подаётся **до** любого публичного раскрытия сути
(демо заказчику под NDA — допустимо; публикация статьи, выкладывание в открытый доступ —
запускает 6-месячную льготу по новизне, ст. 1350 п. 3 ГК, и это риск).

## 2. Трек B — государственная регистрация программы для ЭВМ (ст. 1262 ГК РФ)

Самый быстрый трек: регистрация без экспертизы по существу, свидетельство выдаётся в срок
порядка двух месяцев.

| # | Документ | Комментарий |
| :--- | :--- | :--- |
| B-01 | Заявление на регистрацию программы для ЭВМ (форма ФИПС) | Правообладатель, авторы, название, год создания |
| B-02 | **Депонируемые материалы: реферат** | 700 знаков: назначение, область применения, функциональные возможности, тип ЭВМ, ОС, язык, объём программы |
| B-03 | **Депонируемые материалы: идентифицирующая часть (листинг)** | До 70 страниц исходного текста; персональные данные и секреты исключаются |
| B-04 | Документ об уплате пошлины (или льготе) | Для юрлица и физлица ставки разные |
| B-05 | Согласие авторов на указание сведений и обработку ПДн | — |
| B-06 | Документы о служебном произведении (см. A-12…A-16) | Основание прав организации |
| B-07 | Доверенность представителя | При подаче через представителя |

**Что включать в листинг (B-03) — предложение:** ядро, определяющее новизну, а не
инфраструктурный код:
`backend/app/modules/llm/` (шлюз правил, reasoning, selfcheck, style_guide),
`backend/app/modules/quality/`, `backend/app/modules/risk/`, `backend/app/modules/econ/`,
`backend/app/modules/iam/permissions.py`.

> Регистрировать имеет смысл **зафиксированную версию** (тег в git). Перед подачей — снять
> тег, зафиксировать хеш коммита в реферате.

контролю нарушения через патент.

## 6. Порядок действий (чек-лист)

1. Ввести режим коммерческой тайны — **D-01…D-06** (до любых публикаций).
2. Собрать документы о служебных РИД — **A-12…A-17**, включая аудит лицензий зависимостей.
3. Зафиксировать версию кода тегом; подать регистрацию ПО — **B-01…B-07**.
4. Подать регистрацию БД — **C-01…C-05**.
5. Заказать патентный поиск и заключение о патентоспособности — **A-18…A-20**.
6. Закрыть пробел ПР-03 из `ТЗ_00` §5.2 — выпустить методологический документ расчётов
   ALE/ROSI/Ц_ОМ (RE-22): **без него описание изобретения не собрать**.
7. С патентным поверенным подготовить описание, формулу, чертежи, реферат — **A-01…A-11**.
8. Подать заявку на изобретение, оплатить пошлины, заявить экспертизу по существу.
9. Параллельно: товарный знак **E-06**, реестр отечественного ПО **E-07**.
